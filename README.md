# CodeOrbit Tech Cyber Security Internship Projects

## Projects

### 1. Password Strength Checker
A Python-based tool that checks whether a password meets common strength requirements.

Features:
- Checks minimum password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Displays the password strength clearly

File: `password.py`

### 2. Caesar Cipher Encryption Tool
A Python program that encrypts and decrypts text using the Caesar Cipher technique.

Features:
- Allows the user to enter a message
- Allows the user to choose a shift value (key)
- Encrypts the message
- Decrypts the encrypted message
- Displays both encrypted and decrypted output

File: `caesarcipher.py`
